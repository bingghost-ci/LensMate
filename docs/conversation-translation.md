# 轮流说话的对话翻译

2026-10-24：翻译页使用双方对话卡片，保留右上角「… → 改用文字输入」。本次调整为双按钮录音，增加单次录音上限设置。界面与听感由用户验收；眼镜麦克风问题仍待真机排查。

## 使用流程

默认「我说中文，对方说英语」，两边均可选中文、英文或泰语，支持六方向。每张卡片保留当时的语言方向，之后切换不改写旧句。

1. **选择说话方。** 两种语言下各有一个「开始录音」按钮。点哪一侧，就开始该侧录音。对方使用手机麦克风；我方按现有代码请求眼镜/蓝牙耳机 HFP 输入，实际收音问题见下文。
2. **说完再点一次。** 原按钮变为「结束并翻译」，点击后关闭麦克风，再上传本轮录音进行识别和翻译。录音时另一侧按钮不可用，识别、翻译及播放时双方按钮均不可用；可用左上角「结束对话」取消。
3. **查看双方原话和译文。** 我方卡片靠右，对方卡片靠左。我方译文供对方阅读，默认不自动外放；对方译文按现有路由在眼镜/蓝牙耳机中朗读。
4. **下一轮手动开始。** 播放完毕后不自动开麦，点击任意一侧按钮继续。播放时可点「停止播放」。卡片可重播；我的「朗读给对方」通过手机扬声器播放。

切换语言、离开页面或打开设置会取消当前任务。后台返回不会自动录音。

## 时长与停顿设置

路径：「… → 翻译设置 → 对话节奏」，也可从主设置进入翻译设置。

- **单次录音时长上限**：默认 60 秒，可从 **30～300 秒**按 30 秒调整，双方共用。达到上限立即停止收音、保留本轮内存音频，等你点击「结束并翻译」再提交。
- **我方停顿后自动结束**：默认关闭，双方默认都用按钮启停。开启后，我方停顿达到设定值或达到录音上限时自动提交；对方仍须点击结束。
- **我方停顿时长**：默认 5 秒，范围 1～10 秒。仅在自动结束开关开启时生效。根据声音能量判断，噪声、轻声下的实际断句需用户验收。
- 偏好自动保存，下次录音生效；每轮开始时固定本轮配置。20 秒始终未检测到说话声会取消并提示，不发送空录音。

## 配置与数据边界

选择北京或新加坡，并保存该地域的百炼 API Key，需能调用 **qwen3-asr-flash** 和 **qwen-mt-flash**。密钥仍仅保存在地域独立的 Keychain 中，失败不回退普通配置。普通设置仅保存地域、时长和自动结束开关，不存正文或录音。

流程为：内存录音 → 阿里云识别 → 原文 → 阿里云翻译 → 译文 → 按说话方决定是否朗读。每次请求只携带本轮必要内容，不含助手历史、工具、图片或文档。录音期间不上传，录音仅在内存中，不生成临时文件。卡片清空或进程重启后消失，结束会话时仍保留供查看。

较长的识别原文会按每段不超过 2,000 个 Unicode 标量依次翻译，优先沿句末、空白和完整字符边界分段，再合并到同一张卡片。原文不截断，各段请求不附带历史。失败保留完整原文，可重试翻译；取消后不再提交后续段，晚到的译文不显示、不播放。分段边界处的翻译连贯性待真实长段落联调。

2026-10-24 核对的[阿里云录音识别 API](https://help.aliyun.com/zh/model-studio/qwen-asr-api-reference)限制单段最多 5 分钟，Base64 编码后不超过 10 MB；[模型说明](https://help.aliyun.com/zh/model-studio/asr-model)允许 WAV 任意采样率，服务端重采样至 16 kHz。应用使用 AVAudioConverter 在内存中转换为最高 12 kHz 单声道 PCM16 WAV（8 kHz 输入保持 8 kHz），5 分钟编码后约 9.6 MB。请求入口再次校验时长与编码体积。

继续使用官方共享端点：

- 北京：https://dashscope.aliyuncs.com/compatible-mode/v1/chat/completions
- 新加坡：https://dashscope-intl.aliyuncs.com/compatible-mode/v1/chat/completions

ASR 仅一条 user 消息，input_audio.data 为 WAV Data URL；语言为本轮 zh/en/th，enable_itn=false，stream=false。ASR 请求超时为 90 秒、资源总超时 95 秒，文字翻译维持 30/35 秒。使用临时 URLSession，拒绝重定向。错误不显示服务端原文，日志不打印音频、密钥或正文。

## 眼镜麦克风待排查

用户在 zero 上实测：眼镜可以播放，录音实际来自手机。本次未修改输入/输出路由，也未把该问题标记为解决。

现有代码通过 AVAudioSession 选择 HFP 或 builtInMic，启动前校验系统路由；界面显示系统报告的设备名。这些检查不能替代实际声源验证。只读调试未成功取得运行时路由，手机现已由用户带走；需设备回来后核对我方/对方按钮、录音时的 currentRoute 与 availableInputs，再与远离手机的收音结果对照，查明原因后修复。不得仅凭蓝牙连接或播放成功认定眼镜收音正常。

用户设备回来后：

1. 安装新版，检查中文、英文及跟随系统语言下，两侧按钮始终位于对应语言下方；点击开始，再点结束，不出现重复提交。
2. 设置上限为 120 或 300 秒，录制超过 60 秒，确认不会提前停止；达到设定上限后不继续收音，点击后才翻译。重启确认设置保留。
3. 默认双方都须按键；对方译文播完后麦克风保持关闭。开启我方自动结束后，分别试 2/5/8 秒停顿；对方仍保持手动结束。
4. 与 Codex 一起排查实际麦克风来源；系统设备名、声源实测和路由日志须相互印证。
5. 取消、切语言、切后台、断开眼镜，检查旧结果不会回写或播放；检查长段落识别、翻译质量及朗读听感。
