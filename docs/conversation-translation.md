# 轮流说话的对话翻译

2026-10-24：根据用户的面对面对话流程新增。默认翻译页改为对话卡片；保留文字翻译，位于右上角「… → 改用文字输入」。本批已完成开发与非 UI 验证，真实阿里云语音识别、眼镜音频路由、UI 和听感待用户验收。

## 实际使用流程

默认「我说中文，对方说英语」，两边均可选择中文、英文或泰语，支持六方向。每张卡片记住当时的语言方向，后续切换语言不会改写旧句。

1. **我先说。** 点「开始，我先说」，使用眼镜/蓝牙耳机的麦克风。界面显示实际输入设备名；手机麦克风不同时录音。
2. **说完展示。** 停顿达到设定时长后关闭麦克风，提交这一句的录音进行识别和翻译。右侧卡片显示我的原话与译文，方便对方阅读；默认不把我的译文自动外放。也可点「我说完了」提前提交。
3. **对方说。** 等待期间双方都不录音。点「点此请对方说」后才切到 iPhone 内置麦克风；对方说完，再点「停止录音并翻译」。对方停顿不会自动提交。
4. **翻译给我听。** 左侧卡片显示对方原话与译文，译文用我的语言在眼镜/蓝牙耳机中朗读；朗读期间不采集麦克风。
5. **继续轮流。** 对方译文正常朗读完毕后，自动回到我方眼镜收音。点「结束对话」可立即停止所有任务。手动重播旧句、朗读被中断或发生错误时，不自动恢复录音。

可以让对方先说，也可以在等待对方时点「我再说一句」。卡片上的「在眼镜中重播」用于对方译文；「朗读给对方」是手动通过手机扬声器播放我的译文。

## 可调整的停顿时长

「… → 翻译设置 → 对话节奏 → 我方停顿时长」，也可从主设置的翻译设置进入。

- 默认 **5 秒**，范围 **1～10 秒**，按 1 秒调整，自动保存；下次开始我方录音时生效。
- 只控制我方自动结束录音，对方仍须手动提交。
- 根据声音能量判断停顿，不依据云端文字更新时间；本批不是说话人识别。连续背景噪声或特别轻的声音仍可能影响结束判断，可使用「我说完了」手动提交，真实环境效果需用户验收。
- 没有检测到说话声达 20 秒会取消并提示，不发送空录音。每次最多保存 60 秒音频：我方到上限提交；对方到上限暂停收音，仍等用户点停止再提交。

## 配置与数据边界

在翻译设置选择北京或新加坡，保存该地域的百炼 API Key，需同时开通 **`qwen3-asr-flash`** 和 **`qwen-mt-flash`**。沿用地域独立的 Keychain 存储；密钥保存失败不会回退普通文件。新增普通偏好只有停顿秒数，不存录音或正文。

每句顺序为：内存录音 → 阿里云识别 → 原文 → 阿里云翻译 → 译文 → 按说话方决定是否朗读。录音时没有实时云端上传；每个请求只包含当前句所需数据，不含助手历史、工具、图片或文档。录音仅在内存中，结束/取消后释放，不生成临时文件。卡片只保留在进程内存中，清空或重启 App 后消失；结束会话保留卡片供查看。

2026-10-24 核对的[阿里云录音识别 API](https://help.aliyun.com/en/model-studio/qwen-asr-api-reference)支持北京/新加坡、`zh`/`en`/`th`、Base64 音频以及 OpenAI 兼容 HTTP 协议。采用仍受支持的固定共享域名：

- 北京：`https://dashscope.aliyuncs.com/compatible-mode/v1/chat/completions`
- 新加坡：`https://dashscope-intl.aliyuncs.com/compatible-mode/v1/chat/completions`

ASR 请求仅一条 `user` 消息，内容为 `input_audio.data` 的 WAV Data URL；`asr_options.language` 固定为本轮源语言，`enable_itn=false`，`stream=false`。音频为单声道 PCM16 WAV，最多 60 秒，8～48 kHz，编码后小于官方 10 MB 限制。沿用临时 URLSession、拒绝重定向、超时和取消机制。错误提示不显示服务端原始正文，不打印音频、密钥或识别正文。

## 音频切换与异常

通过系统 HFP 输入选择眼镜/蓝牙耳机，通过 `builtInMic` 选择手机；启动录音前校验实际路由。[Apple 的麦克风选择说明](https://developer-mdn.apple.com/library/archive/qa/qa1799/_index.html)指出，选择 HFP 输入会联动对应输出。本批用这一路由播放给佩戴者，不假设能同时打开两个麦克风。

录音引擎与朗读互斥。麦克风权限未授予、耳机缺失、设备断开、录音流停止或音色缺失都会暂停并提示；不偷偷改用手机收录我方，也不把应在眼镜中播放的译文自动外放。界面显示系统报告的设备名，仍须在真实眼镜上确认收音来源及听感。

语言切换、新录音、重播、取消、进入设置/文字输入、切后台或退出会使旧任务失效。晚到的 ASR/MT 结果不能覆盖卡片或触发旧声音。失败时保留已识别原文，可仅重试翻译，避免再次上传录音。后台返回后不自动开麦，需要重新点击开始。

## 验证与用户验收

已完成模拟器构建、191 项完整 XCTest 回归（新增 20 项）；对方录音上限改为等待手动提交后，相关 20 项测试再次通过。覆盖停顿 1/3/5/10 秒、偏好持久化、对方手动结束、PCM/WAV 与大小限制、三语/地域 ASR 参数、错误与取消、卡片顺序、旧响应隔离、朗读/收音交接、停止及重播。录音/路由测试使用注入设备，未自动操作 UI、录制用户声音或调用真实阿里云接口。

用户验收：

1. 模拟器检查对话布局、语言选择、停顿设置与中英文切换；可从文字输入入口继续验证原有文字功能。
2. iPhone 连接眼镜，配置地域和两个模型权限。确认「我说」显示眼镜设备名；对方录音显示 iPhone 麦克风。
3. 按我方 → 对方流程交替，检查每条原文/译文、自动朗读及朗读后恢复我方收音；让对方停顿超过设定秒数，确认必须点停止才提交。
4. 将我方停顿设为 2/5/8 秒试说，选择合适节奏，重启确认偏好仍保留；检查噪声和轻声情况下的实际断句。
5. 录音/识别/翻译/播放时分别停止、切语言、切后台及断开眼镜，确认没有旧结果、误开手机麦克风或错误外放。

模拟器不能证明眼镜收音与播放；真实鉴权、语义准确率、设备路由和 UI 验收仍待用户完成。
