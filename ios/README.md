# LensMate iOS 工程

这是从固定 OpenVision 提交复制并改名的独立开发副本。完整原有功能保留；已新增独立的阿里云中英泰文字翻译与 iPhone 本地朗读，真实接口与用户 UI 验收待完成。

2026-10-24 已通过 Xcode 签名构建并在 iPhone 14（iOS 18.6.2）安装启动，版本 `0.1.0 (1)`；用户确认可运行，设备安装与进程记录已复核。当前工具链为 Xcode 27.1 / Swift 6.4，早期 Swift 6.2.1 依赖阻碍已解除。眼镜和模型能力仍需分别验收。

```sh
open ios/LensMate.xcodeproj
```

在仓库根目录执行上面的命令。Xcode 中选择 `LensMate` scheme。工程文件已生成，不需要先安装 XcodeGen；`project.yml` 也同步维护了新名字，以后需要重新生成时再使用 XcodeGen。

首次准备与实测状态见 [todo](../todo/README.md)。初次依赖解析需要联网，Meta DAT/MLX 等依赖较大；不要以“工程能打开”代替“可以编译运行”。

本地 `Config.xcconfig` 与 `LensMate/Config/Config.swift` 已由空值模板生成且被 Git 忽略。换一台机器时，分别从对应 `.example` 复制。签名安装前在 Xcode 设置自己的 Team；必要时调整 Bundle ID，并使 Meta 注册信息与回调配置一致。

当前保留上游全部包依赖和 API 版本，不因工具链问题删除功能或随意降级依赖。构建命令与实际错误会记录在 [调试记录](../todo/debug-status.md)。

应用界面支持英文和简体中文。在「设置 → 应用语言」选择「跟随系统」「English」或「简体中文」，立即生效并保存，重启后仍保留选择。默认跟随系统的首选语言：中文地区及字形变体统一显示简体中文；其他未支持的语言回退到英文，不会跳到系统语言列表中的第二种语言。

界面语言不改变语音识别语言、音色、唤醒词、模型提示词或对话内容。权限说明提供中英文资源，系统权限弹窗使用的语言由 iOS 决定。文案集中维护在 `LensMate/Resources/Localizable.xcstrings` 和 `InfoPlist.xcstrings`；品牌、模型标识及用户输入保留原文。

## 中英泰文字翻译

从底部「翻译 → … → 改用文字输入」进入；在「设置 → 翻译设置」选择北京或新加坡，保存该地域的百炼 API Key（需开通 `qwen-mt-flash`）。密钥仅存 Keychain，失败不回退文件。翻译正文默认只留在内存，不进入助手历史。

支持六个方向、交换、自动朗读、停止及重播。源/目标语言与界面语言独立；缺少目标语言系统音色会提示下载。进入翻译会暂停助手音频，离开、切后台或停止会取消请求并阻止旧译文播放。本轮不包含语音识别或眼镜专用路由。

完整模拟器构建和 171 项非 UI 测试通过（新增 26 项）；没有执行 UI 测试或安装新版到用户真机。配置步骤、接口契约、测试命令和用户验收清单见 [文字翻译说明](../docs/text-translation.md)。

## 轮流说话的对话翻译

默认「翻译」页现为对话卡片：我方用眼镜/蓝牙耳机收音，停顿后显示双语；对方用手机按键开始、手动停止录音，译文在眼镜播放，播完再恢复我方收音。两边不同时录音。右上角「…」保留文字输入及设置入口。

「翻译设置 → 对话节奏」可将我方停顿时长设为 1～10 秒，默认 5 秒，自动保存；不影响对方手动提交。语音翻译还需开通同地域的 `qwen3-asr-flash`。构建与非 UI 测试通过；实际眼镜路由、云端语音识别及 UI 待用户验收，见[对话翻译说明](../docs/conversation-translation.md)。
